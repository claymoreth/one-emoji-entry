Entry for the make.fun competition [One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f).

The brief: one emoji, one smile — nothing else. This entry is a single
smiling face with hearts, the warmest single character there is.

## How it works

`main.py` writes exactly one emoji (U+1F970, smiling face with hearts) to
`entry.txt` in the output directory — UTF-8, no trailing newline, nothing
else. The output directory comes from the `MAKEFUN_OUTPUT_DIR` environment
variable when set, falling back to `/output`.

## Run

```sh
python3 main.py
```
